# EV-056 — 복습 변형 규칙(learning-paths-2.1) 로컬 검증

2026-10-25 Asia/Seoul / WBS-360·CR-013 / 기준선 1.9.0. 기준 commit f58feb9280fbe7a49eb6c8b2db36f3ca3063a97a 위에서 작업했다.

## 변경

- `backend/learning_paths.json`: 버전 learning-paths-2.1, `review.repeat_gap_days=7` 추가. `rules`와 206개 items는 바이트 단위로 보존(기존 보존 테스트 통과).
- `backend/curriculum.py` / `src/recommendation.ts`: 기한 도래 문항이 독립 해결(streak>0) 뒤 7일 미경과면 같은 개념의 미학습 적격 문항을 `practice`로 대신 선택한다. 보충(remediation) 문항 → 같은 단계 → 카탈로그 순으로 고른다. 같은 개념의 복수 기한 문항은 한 자리만 쓴다. 대체 후보가 없으면 원래 문항을 `review`로 낸다. 도움/오답 뒤(streak=0) 문항은 그대로 다음날 복습한다. 추가 학습은 간격 안의 문항을 건너뛴다. trace에 `review` 정책과 practice 이유 문구를 추가했다.
- 화면 라벨 `다시 연습`(practice)은 기존 ExerciseCard에 이미 있어 UI 변경이 없다.
