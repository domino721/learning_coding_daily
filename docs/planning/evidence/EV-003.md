# EV-003 — 기본·추가 학습 합계 표시 회귀 검증

대상: WBS-030, REQ-002·REQ-009. 기준일 2026-10-15, Asia/Seoul.

검증한 구현 commit: `2404fab3160a5ba4d4a770ee75f5439e42b8f46b`.

## 문제와 수정

사용자는 기본 5문제와 추가 5문제를 마쳤는데 5문제로 보인다고 보고했다. 저장소의 브라우저/서버 집계는 추가 묶음을 포함했지만 홈의 큰 진행률은 기본 목표의 5/5였고, 완료 화면도 해당 묶음 5문제 결과만 보여 혼동을 만들었다. 사용자의 실제 기기 저장 자료를 직접 조회한 것은 아니다.

홈·완료·기록 화면에 오늘 총합과 기본/추가 내역을 동일하게 표시한다. 기본 진행률과 돌아보기 버튼은 기본 학습임을 명시하고, 정답/해설 통계에는 이번 기본/추가 묶음의 결과라고 표시한다. 완료 화면을 열기 전에 합계를 갱신하며, 갱신 실패는 기존 오류/재시도 경로에서 처리한다. 저장 형식과 실제 기록은 변경하지 않았다.

기존 누적 기록 요구의 버그 수정으로 설계/계획 1.0.0과 WBS의 작업 정의는 유지한다. 완료 작업의 유지보수 이력은 LOG-005·006과 새 근거로 추가했다. 후속 WBS-210의 순서는 바꾸지 않았다.

## 실행 결과

- 수정 전 새 회귀 기대를 실행했을 때 오늘 누적 학습 표시가 없어 실패함을 확인했다.
- `bash scripts/check.sh`: 관리 검사·콘텐츠 일치·포맷·타입 검사·빌드 통과. pytest 52개 통과.
- 확장한 E2E의 최초 실행에서는 화면 뒤로 가기 버튼의 실제 접근성 이름에 화살표가 포함된 것을 빠뜨린 선택자로 2개가 실패했다. 앱의 누적 합계 검증은 통과한 상태였고, 선택자를 바로잡았다.
- 최종 `npm run test:e2e`: 6개 모두 통과. 브라우저 단독 모드와 서버 모드에서 0→5→6→10→11의 누적 변화, 기본 5와 추가 0/1/5/6 내역, 완료 화면·기본 결과 다시 보기·홈·기록·새로고침을 검증했다. 해설로 마친 문제도 합계에 포함한다. 기존 기록 이전과 오류 복구 검증도 통과했다.
- 모바일 완료 화면 캡처에서 오늘 총 10문제, 기본 5·추가 5, 이번 추가 학습 5문제 결과의 구분을 확인했다. 생성 캡처는 로컬 테스트 산출물이며 Git 추적 대상은 아니다.
