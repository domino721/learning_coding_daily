## 보존과 작성

10월 16일 구형 미커밋 API 실험 21파일을 source tar/patch/manifest와 Git stash로 보존하고 최신 main으로 fast-forward했다(LOG-026). 그 실행은 마지막 검증 기록 작성 명령 전에 자동 승인 검토가 사용량 한도로 실패해 게시하지 못했다. 10월 17일 실행에서 미게시 변경을 다시 source tar/patch로 백업하고 최신 main 및 게시 배치 부재를 확인했다. 미게시 5문제를 재검수해 오늘 배치 codex-2026-10-17로 확정했다. 두 날짜를 합쳐 10개를 게시하지 않는다. 백업·개인 DB·API 실험은 커밋에 포함하지 않는다.

부족한 pandas-select 수준2·numpy-mask 수준1과 범주형 전처리, 기존 단일 조인/NOT IN과 다른 다중 조인·상관 NOT EXISTS를 추가했다. 작성 후 각 문제를 별도로 다시 풀고 정답·보기 유일성·지문·코드·해설·두 단계 힌트·난이도·시간을 검수했다. 참조 풀이와 경계 사례는 docs/content_batches/2026-10-17.md에 있다. 이는 Codex 검수이며 Gemini/Argon 호출이나 외부 모델 API 호출은 없다. 난이도·시간은 편집 추정값이다.

## 원격 게시 상태와 한계

이 EV 작성 시점에는 커밋·원격 게시·Pages 실행 결과가 아직 없다. 공개 URL 직접 요청은 환경 프록시 CONNECT403으로 막혔다. 게시 후 GitHub runner가 실제 공개 URL에서 HTML/JS/CSS를 받아 일치 여부를 확인하며, 해당 커밋의 성공 여부와 결과는 새 EV에서 기록한다. 단순 커밋/배포 요청을 성공으로 표시하지 않는다. 실제 사용자 휴대폰·학습 효과 검증은 모바일 에뮬레이션 결과와 다르다. 개인 학습 로그·키를 외부 전송하지 않았다.
