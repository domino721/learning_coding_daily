## 변경과 재발 방지

- 기존 추가 SQL 6개는 테스트용 `reference_setup`만 있고 화면에 입력이 없었다. 전체 CREATE/INSERT를 주석으로 표시하고 v2로 올렸다. ID·쿼리·정답·보기·힌트·난이도는 유지했다. 과거 60개 해시 fixture를 수정하지 않고, 수정 6개의 입력/버전만 제외한 원본 일치와 나머지 문항 전체 일치를 검증했다.
- 새 SQL 5개는 빈 집합/모두 NULL/평균 분모/중복 합계/조건을 만족하는 주문 연결을 다룬다. 전체 70개, 활성 Python48/SQL17, 서술형 보류5개다. 같은 날짜의 중복 배치는 없다.
- 표시된 입력만 독립 SQLite에 만들어 전체 테이블·열·행과 정답을 검증한다. 데이터 누락, 합계만 같은 잘못된 데이터, 조인 테이블 누락의 실패 사례를 검사했다. 웹 내보내기/게시의 콘텐츠 검사에도 적용했다. 기존 SQL compact/pipe 표를 포함한 18개 모두 통과했다.
- 과거 저장 쿼리에는 ID·쿼리가 같은 보완본의 주석만 화면에서 보충한다. 실행 쿼리가 바뀌는 대체는 금지하며 snapshot·v1·답안·시도·진도를 덮어쓰지 않는다. 풀이/해설에 동일 적용하고 입력 주석은 320px에서도 줄바꿈한다.
