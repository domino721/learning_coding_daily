# EV-078 — Windows 트랙 보류 로컬 검증

2026-10-31 Asia/Seoul / WBS-395·CR-022 / 기준선 1.18.0. 별도 작업 트리(origin/main 6b9b9d8 위) 검증이며 원격 저장·Pages 게시 전이다.

## 트랙과 문항

- 트랙은 다섯이다: Python 기초 66·Python 데이터 분석 171·SQL 71·터미널 33·Git 26문항(코딩테스트 준비 중). 서버 `/api/tracks`와 웹 번들(`src/curriculum.json`)의 트랙 목록에서 Windows(`windows`)가 빠졌고 다섯 트랙의 합이 활성 문항 367개다.
- 보관 원본은 그대로 389문항·개념 53개다. 서술형 5개와 Windows 17문항(version 2)은 보관하되 추천하지 않는다. Windows 문항·개념 4개·경로·카드·검수 기록과 모든 (id, version)이 바뀌지 않아 카탈로그 snapshot(`tests/fixtures/catalog-published.json`)을 다시 만들지 않았고 보존 검사가 그대로 통과한다.
- 서버 `select_exercises`와 브라우저 `selectExercises`는 같은 보류 판정(`HELD_DOMAINS`/`active`)으로 Windows 문항을 어떤 트랙과 트랙 없는 시험용 풀에서도 고르지 않는다. Windows가 아닌 문항·개념 가운데 Windows 문항·개념을 선수나 보충 문항으로 두는 것은 없다(경로 원본으로 확인).
- 트랙 없는 시험용 풀의 첫날 다섯째 문항은 CR-020 때처럼 stats-median-01이다. 공유 fixture(`tests/fixtures/recommendation.json`) 6곳을 CR-021 이전 값으로 되돌렸고 두 엔진 테스트가 같은 값을 낸다.
- Windows 세션 시작은 서버·브라우저 모두 409(아직 준비 중인 트랙)이고, 서버 대시보드의 windows 요청은 422다. 저장된 Windows 선택은 기본 트랙(Python 데이터 분석)으로 돌아간다. 이미 푼 Windows 기록과 오늘 시작한 Windows 세션은 지우지 않는다(세션은 문항 snapshot을 담는다).

## Windows 실행 검사

- `quality.yml`의 windows 작업을 같은 내용의 수동 워크플로 `.github/workflows/windows.yml`(workflow_dispatch)로 옮겼다. Pages 게시는 Ubuntu 품질 검사만 기다린다.
- 웹 내보내기와 테스트는 그대로 Windows 문항의 시작 상태·검수 기록·정답 구성을 실행 없이 검사한다. 다시 열 때는 작업을 `quality.yml`로 되돌려 게시 조건으로 삼는다.

## 화면

- 320×740: 트랙 카드 5장이 세 장씩 두 줄(3+2, 카드 높이 40px)이고 시작 버튼 아래끝 650px이 하단 메뉴(664px)보다 14px 위다. 가로 넘침은 없다. 홈의 현재 제공 수는 367개다.
- 600px: 다섯 칸 한 줄(카드 105×53px)이고 시작 버튼 아래끝은 514px다.
- 설계 페이지: 활성 문항 367·보관 원본 389·학습 개념 53·트랙 5. Windows 문항은 보류 문항으로 표시된다.

## 로컬 검사

- `bash scripts/check.sh`: planning check(설계 1.18.0/계획 1.18.0, 작업 42개), export --check, format:check, build, Node 계약 테스트 26/26, pytest 1398 passed.
- 모바일 E2E 첫 실행은 52 passed·2 failed였다. 설계 페이지 테스트가 활성 문항 수를 서술형만 빼고 셌기 때문이다(기대 384, 화면 367). 보류 Windows 문항을 빼고 세도록 고치고, Windows 문항이 보류 문항으로 보이는지 함께 확인하게 했다. 다시 실행한 전체 E2E는 54 passed, 15 skipped(프로젝트 비해당)다.
- `scripts/compare-engines.py`: 다섯 트랙 재생에서 두 엔진 결과가 같다(exit 0).

## 범위와 한계

- 보존 규칙상 Windows 문항 데이터는 공개 번들에 남는다. 홈·추천·트랙 목록에는 나오지 않고, 이미 푼 기록과 설계 페이지에서만 보인다.
- 실제 학습 효과와 Windows 트랙을 다시 열지는 베타 반응(WBS-520/530)을 보고 사용자가 정한다.
