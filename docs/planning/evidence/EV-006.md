# EV-006 — Pages 배포 재실행 오류와 복구

대상: WBS-010·WBS-030, REQ-009·010. 기준일 2026-10-15, Asia/Seoul.

돌아보기 수정 commit `73956c2923f58d16e61e090dda930bedeb021dbc`를 main에 push했다. [Publish mobile web 실행](https://github.com/domino721/learning_coding_daily/actions/runs/38737102317)의 빌드와 관리 검사·artifact 업로드는 성공했다.

첫 시도(job 116429073127)는 최종 Pages 생성 API에서 HTTP 500으로 실패했다. 실패 작업 재실행 요청은 성공했지만 두 번째 시도(job 116429452050)는 같은 실행의 github-pages artifact가 2개라는 오류로 게시에 실패했다. 이 결과를 배포 성공으로 기록하지 않는다.

워크플로의 업로드 이름과 게시 artifact_name을 모두 `github-pages-${{ github.run_attempt }}`로 맞춰 재실행끼리 충돌하지 않도록 수정했다. 변경은 기존 Pages 배포 경로의 복구이며 새 서비스·비용·학습 데이터 변경은 없다. 앱 검증 결과는 EV-005에 유지한다. 관리 검사와 다음 원격 실행에서 변경을 검증한다.
