## 실제 공개본 검증

운영 주소는 https://domino721.github.io/learning_coding_daily/ 이다. publish의 **Verify the public site serves this build** 단계가 성공했다. 해당 커밋의 `scripts/verify-published-site.py`는 공개 HTML의 빌드 참조가 같은지 확인하고 문제 데이터가 든 청크를 포함한 전체 JS/CSS를 직접 받아 배포 빌드와 SHA256을 대조한다. 따라서 push나 배포 요청만 확인한 것이 아니라 GitHub runner의 실제 공개 파일 대조까지 성공한 상태다. 환경에서 직접 공개 URL을 조회한 것으로 표시하지 않는다.

Python15·SQL3, 기초/적용/전이 각6개가 기존 사이트에 게시됐다. 현재 보관177개·활성Python134/SQL38·서술형보류5개이며 기존159개·선수 경로·설계 카드/초안·18개개념·운영2.0·기존 UI/답안/저장키/복습/2회제출을 보존한다. 특정 새 문제의 추천 시점은 기존 선수·개념 근거 규칙을 따른다. 이미 시작한 세션의 snapshot을 교체하지 않는다.

이 증거와 완료 로그는 배포 이후 문서 전용 `[skip ci]` 후속 커밋으로 저장한다. 설계·계획1.8.0과 다음WBS-520을 유지하며, 실제 사용자 장기관찰·학습 효과·시간/난이도 보정은 WBS-520/530에서 별도로 확인한다.
