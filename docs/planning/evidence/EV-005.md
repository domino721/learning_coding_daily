# EV-005 — 오늘 전체 풀이 돌아보기 검증

대상: WBS-030, REQ-002·006·009. 기준일 2026-10-15, Asia/Seoul.

## 요청과 산출물

기본 학습 돌아보기에서 오늘 10문제를 풀어도 기본 5문제만 나온다는 사용자 제보를 처리했다. 최신 원격 main `3597540be2eb40c407fb465bdcdad1e4283e5be5`의 상단 발자국·누적 표시·저장 안내를 보존하고 이전 로컬 수정과 통합했다. 사용자는 실제 사이트 배포까지 요청했다.

서버와 브라우저의 dashboard에 오늘의 모든 묶음을 순서대로 제공한다. 완료 화면과 오늘 학습 돌아보기는 완료한 문제만 모아 목록·해설·정답/해설 수를 합산한다. 같은 문제를 반복 연습한 결과는 묶음별로 각각 표시한다. 미완료 문제는 결과에 넣지 않는다. 저장 버전·기존 기록·설계와 계획 기준선 1.0.0은 유지한다.

## 로컬 검증

- `bash scripts/check.sh`: 관리 검사·콘텐츠 일치·포맷·타입·빌드, pytest 52개 통과.
- `npm run test:e2e`: 서버·기기 저장 모드 모바일 Chromium 6개 통과.
- 브라우저에서 기본 5개와 추가 5개 완료 시 10개 목록 및 모든 해설을 확인했다. 추가 묶음 중간의 6개·11개 결과와 미완료 문제 제외, 두 추가 묶음 완료 후 15개 목록·합산 결과, 새로고침·기록 화면·기존 기록 호환을 확인했다.
- 서버에서 7개 묶음의 31회 풀이와 서로 다른 문제 30개, 반복 풀이 보존, 미완료 정답/해설 비공개, 다음날 기록 분리를 확인했다.
- `git diff --check` 통과. 실제 휴대폰과 학습 효과는 검증하지 않았다.

원격 Pages 배포 성공은 이 로컬 검증과 별도로 확인한다.
