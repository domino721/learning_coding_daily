## 원인 조사

- 카탈로그를 바꾼 커밋 20개(`src/curriculum.json` 이력)를 비교해 문항 ID 삭제·변경이 0건임을 확인했다. 버전만 오른 문항은 10-15·10-17 초기 정비와 10-28 일일 정비 3개(pandas-select-03·pandas-filter-03·pandas-sort-01)다. 진도는 문항 ID로 저장되므로 배포 뒤에도 푼 문항이 새 문항으로 돌아오지 않는다. 가상 기록에서 푼 문항 30개의 버전을 올려도 새 문항으로 다시 고른 경우는 0건이었다(수준 근거에서만 빠짐).
- 2.2 웹 추천 코드로 모두 맞히는 가상 학습자(Python, 기본 5문제)를 재생했다. 1~3일은 새 문항 5개, 4~7일은 다시 연습 3개, 8일째부터 매일 5문제 중 3문제가 이미 푼 문항이었다. 기한이 지난 복습은 8일째 25개에서 28일째 53개로 하루 약 2개씩 늘었다. 같은 문항은 14일마다 끝없이 돌아왔다.

## 한 번에 맞힌 문제의 재등장 점검

최종 2.3 웹 코드로 90일 재생했다. 모두 맞히는 학습자·1/4·1/2 확률로 도움을 받는 학습자 모두 첫 시도 정답 뒤 7일 안에 같은 문항이 다시 나온 경우가 0건이다(기한이 되면 같은 개념의 다른 문항으로 대신). 같은 개념에 대신 낼 미학습 문항이 하나도 없으면 2.1 규칙대로 원래 문항이 3일 뒤 나올 수 있다. 모두 맞히는 학습자는 7일 뒤부터 같은 문항이 최대 2번 더 나온 뒤 졸업했다. 사용자에게 보고했고 사용자가 이 설계(3일·7일 확인 뒤 졸업)를 유지했다.
