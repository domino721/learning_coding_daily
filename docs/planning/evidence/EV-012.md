# EV-012 — 추천·기록 보존 모바일 통합 검증

대상: WBS-260·340 및 EV-010·011 관련 구현. 2026-10-16, Asia/Seoul.

- `uv run --frozen pytest -q`: **170개 통과**, 기존 Starlette/httpx 경고 1개. 콘텐츠 실제 참조·개념/추천·제출/자정·SQLite 이전·복구/충돌 rollback·관리 검사 포함.
- `npm run test:contracts`: **12개 통과**. 공통 추천 fixture의 Python/TypeScript 선택 ID 일치, 간격 규칙, 파일 검증, 중복/충돌/부분 진도 보존, 잘못된 원본/키 거절.
- `npm run test:e2e`: **14개 통과, 4개 해당 없음으로 건너뜀**. 18개 중 브라우저 저장소 손상/쓰기 실패/원본 복구/브라우저 자정의 네 경우는 SQLite 서버 프로젝트에 중복 실행하지 않는다.
- 모바일 항목: 320px 가로 넘침 없음, 단일 시작·문항별 형식·힌트 미노출·오답/힌트·기본/추가 15문제 합산, 임시 답안 재접속, 전체 날짜별 원래 제목/해설과 누적 수치, 서술 답안 보존.
- 복구 항목: 같은 파일 반복 병합 시 중복 없음, 파일 변조/미지원 버전 거절, 주 저장본 삭제/손상 후 IndexedDB 복구, 두 저장소 쓰기 실패 시 미완료 보존과 안전한 재시도, 손상 원본 보관 후 명시적 파일 복구, 한국 시간 자정 전후 오늘 0/누적 1 유지.
- 초기 확장 검증에서 복구 완료 뒤 오류 메시지 해제/화면 전환 문제를 발견해 수정했다. 쓰기 실패 주입 테스트는 학습 묶음 저장이 끝난 뒤 실패를 주입하도록 대기를 보완했다. 최종 전체 모바일 실행은 모두 통과했다.
- 빌드·포맷·콘텐츠 일치·관리 검사를 함께 수행한다. 이후 백업 파일명 날짜를 Asia/Seoul로 맞춘 표시 변경은 타입/빌드로 재확인했다.

SQLite의 비어 있는 임시 답안은 null, 브라우저는 빈 문자열/누락일 수 있으며 동일하게 빈 입력으로 처리한다. 서버 모드는 개인용 로컬 개발 DB이고 웹은 각 브라우저별 저장이다. 두 모드에서 계정 동기화가 제공된다는 뜻은 아니다. 에뮬레이션·규칙 검증을 실제 기기 사용이나 학습 효과 입증으로 대체하지 않는다. 원격 배포 성공은 후속 EV-013으로 별도 기록한다.
