# EV-041 · 발자국 일수·집계 위치와 소개 영역 여백 후속 조정

2026-10-20 Asia/Seoul / WBS-010 / EV-040의 사용자 후속 UI 요청. 기준 main `2879bc17508cb27b197bc6d9ce524989192240ac`은 fetch 후 동일함을 확인하고 이전 로컬 변경을 별도 패치로 보관했다.

## 변경

- 발자국 제목 아래에 학습 일수를 두고 그 바로 아래에 오늘 풀이 총합을 배치한다.
- 오른쪽 전체 트랙·기본·추가/이전 집계를 카드 제목 높이에 맞춰 올린다.
- 요일·총합 주변 간격을 줄여 홈 발자국 카드 높이를 약 171px에서 147px로 줄였다.
- 520px 이상 좌우 배치에서 소개 제목을 ‘오늘도,’와 ‘한 걸음 더.’ 두 줄로 정리하고 설명 줄 길이를 맞췄다. 소개 높이는 약 134px로, 카드 아래쪽과의 높이 차이는 약 13px다. 좁은 화면에서는 기존 한 줄 제목과 세로 배치를 유지한다.
- 집계 계산·문항·학습/저장/추천·스키마는 변경하지 않는다. 결과 화면의 누적 표시에는 발자국 제목과 일수가 추가되지 않는다.

## 검증 범위

- 타입 검사와 서버/웹 프로덕션 빌드, 변경 파일 포맷 검사 통과.
- `UV_CACHE_DIR=/workspace/.cache/uv uv run --frozen pytest tests/test_api.py`: 20개 통과, 기존 Starlette 경고 1개.
- `npm run test:e2e -- tests/e2e/learning.spec.ts`: 웹/서버의 모바일 학습·이어하기·기록·테마·복구 4개 통과. 기존 위치 검사에 학습 일수가 풀이 총합 위에 있고 오른쪽 집계가 일수보다 위에 있는지 추가 확인한다.
- 별도 Chromium에서 5문제를 실제로 풀고 320·393·520·565·1024px 너비의 가로 넘침 없음, 일수/총합 순서, 오른쪽 집계 위치를 확인했다. 좌우 배치의 카드/소개 높이 차이는 모두 20px 미만이다. 565px 라이트·다크 PNG는 `/workspace/scratch/daily-ui/revised-home-565.png` 및 `revised-home-565-dark.png`로 보관했다.
- 관리 문서 render/check, 기준 main 대비 과거 기준선·증거·이력 불변 검사, `git diff --check` 통과.

첫 모바일 실행 중 소개 문구의 후속 수정을 적용해 실행을 중단하고, 코드 고정 후 전체 4개를 다시 실행했다. 이전 실행의 부분 결과로 최종 성공을 판정하지 않는다.

기존 설계/계획 1.8.0 내 화면 유지보수로 처리한다. 기존 Pages에는 게시 전이며 실제 휴대폰 사용 관찰과 원격 배포 성공은 이번 근거의 범위가 아니다. 다음 계획 작업 WBS-520을 유지한다.
