# EV-008 — 세 가지 풀이 모드와 기존 기록 호환 검증

대상: WBS-040, REQ-005·006·009·014. 검증일 2026-10-16, Asia/Seoul.

최신 main `041a66c`의 오늘 전체 학습 돌아보기·Pages 배포 재시도 수정을 보존한 설계/계획 1.1.0 구현이다. 신규 기본/추가 학습은 단답형을 기본으로 하며, 객관식·서술형으로 선택할 수 있다. 문제 화면의 모드 변경은 현재 묶음의 미완료 문제에 적용한다. 완료 항목의 답안·상태·모드는 보존한다.

- `uv run --frozen pytest -q`: 96개 통과(앱/콘텐츠 86, 관리 10). 기존 Starlette/httpx 사용 중단 예정 경고 1개.
- `npm run test:e2e`: 브라우저 저장/서버 저장의 모바일 Chromium 6개 모두 통과. 최종 통합 실행 1.5분.
- `npm run build`, `npm run format:check`, `python3 scripts/export-content.py --check`, `python3 scripts/planning.py check`, `git diff --check` 통과.
- 서버 검증: 단답형 기본, 모드 변경/재시작 복구, 완료 기록 보존, 객관식 보기 외 입력 거절, 6개 빈칸의 보기, 서술 답안 저장·중복 제출·다음날 복습, SQLite v1/v2→v3 이전 및 외래키/답안/진도 보존.
- 콘텐츠 검증: 기존 30문제의 실제 라이브러리/SQL 참조 결과, 각 문제의 정답/오답 보기, 단답형 공백·따옴표·숫자 표기와 잘못된 입력. 사용자 코드는 실행하지 않는다.
- 모바일 검증: 320px에서 입력/모드 선택과 가로 넘침 없음, 힌트·오답 재시도·모드 전환, 모드 새로고침 복구, 서술 제출 후 내 답안 표시와 돌아보기 보존, 기본/추가 총 15문제 합산, 과거 브라우저 기록 호환과 저장 실패 복구.
- 사이트 주소는 기존 EV-007에도 이미 있었다. README·AGENTS·PHONE_SETUP의 앞부분에 주소/저장소/기존 Pages 배포 경로를 명시하여 이후 작업에서 먼저 확인하도록 했다.

초기 샌드박스는 로컬 포트 열기를 차단하여, 최종 테스트는 로컬 서버 실행을 허용한 환경에서 수행했다. 최초 확장 E2E는 기존 30초 전체 테스트 제한에 도달했으며, 여러 모드와 여러 묶음을 검증하는 시나리오만 90초로 조정해 재검증했다.

서술형은 자유 문장을 자동으로 정오 판정하지 않는다. 최대 2,000자 답과 이유를 저장한 뒤 정답·해설과 비교하며 ‘해설로 배움’으로 기록한다. 실제 휴대폰 관찰·학습 효과·원격 배포 성공은 이 로컬 검증에 포함하지 않으며 배포는 별도 증거로 확인한다.
