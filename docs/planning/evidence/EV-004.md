# EV-004 — 발자국 상단 배치와 저장 안내 검증

대상: WBS-010·WBS-030, REQ-001·002·009·010. 기준일 2026-10-15, Asia/Seoul.

구현 commit: `2227271b1820e8b1a22c0e28d43154452f1543fb`.

## 요청과 산출물

사용자는 푼 문제에서 성취감을 느낄 수 있도록 발자국을 위에 배치하고, 정답률·결과·완료 기록의 저장 위치를 설명해 달라고 요청했다.

홈의 기존 최근 7일 발자국을 학습 카드 위로 이동했다. 오늘 총합/기본·추가 내역을 이 카드에 모으고 숫자를 강조했다. 미학습/일부 학습/목표 달성/추가 학습에 맞는 문구를 표시한다. 화면 배치와 설명만 개선했으며 학습 흐름·기록 계약·저장 구조·기준선·다음 WBS는 유지한다.

`docs/LEARNING_RECORDS.md`에 브라우저 localStorage 저장 항목, 별도 백분율 정답률 및 종합 정답률 화면 미제공, 첫 시도 정답률과 최종 정답 완료의 차이, 기기/브라우저 간 동기화와 백업 미지원, 서버 개발 모드의 SQLite 경로를 실제 코드에 대조해 기록했다.

## 검증 결과

- `bash scripts/check.sh`: 관리 검사·콘텐츠 일치·포맷·타입·빌드 통과. pytest 52개 통과.
- `npm run test:e2e`: 6개 모두 통과. 두 실행 모드에서 발자국이 첫 화면 안에 보이고 학습 카드보다 위에 위치함을 확인했다. 기본+추가 10문제 완료 후 합계와 추가 학습 성취 문구를 확인했다. 기존 0→5→6→10→11 누적, 기록/새로고침, 이전 기록 보존, 오류 복구 검증도 통과했다.
- 모바일 홈 캡처에서 상단 배치·글자 크기·7일 표시와 카드 간격을 확인했다. 캡처는 로컬 테스트 산출물이다.
- 브라우저 저장 `src/browserApi.ts`, 결과 타입 `src/api.ts`, 서버 DB 경로 `backend/main.py`, 테이블 `backend/storage.py`를 확인했다. 사용자 휴대폰의 실제 저장 값은 조회하지 않았다.

실제 기기 관찰과 학습 효과를 검증한 것으로 해석하지 않는다. 원격 Pages 배포는 이 로컬 검사 기록과 별도로 확인한다. 기존 TestClient/Node 환경 경고는 실패가 아니었다.
