# EV-010 — 문항별 형식·난이도와 규칙 기반 커리큘럼

대상: WBS-210·230·240·250·310·320·330, REQ-003·005·006·007·008·011·012·014. 2026-10-16, Asia/Seoul.

- 기존 30문항의 ID·내용을 보존하고 각 영역 6개씩 새 상황으로 적용하는 30문항을 추가했다. 총 60개(pandas 16, 나머지 네 영역 각 11)와 18개 개념/선행 맵이다.
- `backend/difficulty.json`에 문항마다 형식·수준·추론 단계·코드 부담·전이·오개념·이유·보정 상태를 명시했다. `docs/CURRICULUM.md`에 기준·60문항 표·초기 보정 한계를 기록했다.
- 별도 모드/수준 선택을 제거하고 ‘오늘 학습 시작’에서 기초 혼합으로 시작한다. 작성자 지정 형식을 사용하되 이미 진행한 묶음은 바꾸지 않는다.
- 승급 근거는 서로 다른 문제/날짜의 독립 풀이이며 하루 첫 관찰만 센다. 힌트·재시도·서술형 비교·같은 날 반복으로 승급하지 않는다. 제한된 적용/전이 탐색과 최근 두 날의 보완 규칙은 숙련 인정과 구분한다.
- 도움은 1일, 독립 정답은 3일, 다른 날 독립 복습은 7일·14일 후보다. 같은 날 반복만으로 간격을 늘리지 않는다. 기본 복습 상한 3개·기본 목표 5개·계속 가능한 추가 학습을 유지한다.
- Python/SQL 실행 참조 검증은 기존/신규 전체 60문항을 확인한다. 신규 30개는 실제 라이브러리/SQLite로 결과를 검증하고 개별 2단계 힌트·해설·오답 보기를 작성했다. 사용자 코드는 실행하지 않는다.
- 공통 fixture는 신규·같은 날 반복·다른 날 다른 문제·같은 문제 회상·힌트/재시도·서술형 사례에 대해 Python과 TypeScript의 개념 상태 및 선택 ID까지 일치함을 검증한다.

최종 관련 전체 pytest 170개, Node 계약 12개 통과. 실제 휴대폰 사용 자료나 난이도/학습 효과의 실측 검증은 아니다. 일부 개념은 문항 수가 제한되어 숙련을 과장하지 않으며, 실제 사용 자료에 따른 보정은 다음 WBS-510부터 수행한다.
