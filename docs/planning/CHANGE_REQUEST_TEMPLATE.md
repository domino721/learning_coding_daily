# 변경 요청 기록 양식

이 양식 자체가 요청은 아니다. 실제 요청은 `changes.json`에 다음 CR ID로 추가한다.

- ID / 날짜 / 제목 / 상태: proposed → accepted → applied 또는 deferred/rejected/superseded
- 원래 요구사항·WBS:
- 새 요청과 이유:
- 승인 근거: 사용자의 명시적 지시 또는 기준선 내 기술 판단. 미합의 사항은 별도 표시
- 범위·데이터·비용·일정 영향: 미정이면 미정으로 기록
- 대안 / 선택 / 포기한 장단점:
- 새 설계 버전 / 새 계획 버전 또는 버전 변경 불필요 사유:
- 추가·변경·대체 WBS / 의존성:
- 완료 조건 / 이전·회귀·사용성 검증:
- 구현 근거 / 미해결 조건:
