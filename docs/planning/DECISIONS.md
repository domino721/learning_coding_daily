# 결정 기록

2026-10-15, Asia/Seoul. ADR-001~006은 실제 사용자 합의와 현재 코드에서 소급 정리했다. 독립적인 사전 리뷰가 있었다는 뜻은 아니다. 새 중요 결정은 다음 ADR 번호와 CR/WBS를 연결해 추가하며, 기존 결정을 바꾸면 새 항목에서 대체 관계를 명시한다.

| ID | 결정·상태 | 근거와 결과 | 변경 연결 |
| --- | --- | --- | --- |
| ADR-001 | 데이터 분석을 NumPy/pandas/SQL/통계/scikit-learn을 포괄하는 트랙으로 채택 | 사용자 범위 명시. 도구를 별도 앱으로 쪼개지 않음. pandas 내부 저장 ID는 호환용 유지 | CR-001, WBS-020 |
| ADR-002 | 하루 5개는 목표, 추가 5개씩 계속 가능 | 완료 후 더 풀 수 없다는 사용자 지적. 기본과 추가 묶음을 분리해 결과 보존 | CR-003, WBS-030 |
| ADR-003 | 풀이 전 단서 제거, 요청형 힌트·완료 후 해설 | 지문만으로 정답이 추론된다는 사용자 지적. 코드 이해와 오개념을 검수 | CR-002, WBS-020 |
| ADR-004 | 현재 개인용 무료 GitHub Pages + 브라우저 저장, 서버 모드 유지 | 사용자가 휴대폰 링크·무료 시작 선택. 비용 없이 사용하나 기기 간 동기화와 데이터 삭제 복구는 미지원 | WBS-010, R-003, R-007 |
| ADR-005 | 사용자 코드의 API 프로세스 내 임의 실행을 채택하지 않음 | 현재는 문자열 채점. 코드 작성은 모바일 Worker PoC·한도 검증 후 도입 | WBS-410~440, R-004 |
| ADR-006 | 설명 가능한 규칙으로 먼저 개인화 | 모델/외부 API 의존 없이 전이·복습 경계 사례를 검증할 수 있음. 실제 숙련도 규칙은 아직 미구현 | WBS-210~260 |
| ADR-007 | 설계/계획 기준선과 진행 상태 분리, 기존 기준선 고정 | 사용자의 WBS·버전 관리 요청. 상태 갱신은 Git 이력으로, 범위/계획 변경은 새 버전과 CR로 추적 | CR-004, WBS-110 |

미결정: 진단 길이/배치 기준, 숙련 전이 수치, 복습 간격 조정, 실행 엔진/한도, 실제 기기 지원 범위, 출시 인증·동기화·비용, 네이티브 패키징. 다음 WBS에서 확정하기 전까지 구현된 기능 또는 사용자 확정 선택으로 표시하지 않는다.
