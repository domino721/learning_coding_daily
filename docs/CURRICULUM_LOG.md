### 근거

1. 사용자가 평균 15, 표준편차 5로 새 입력 30을 변환하는 문제의 해설을 제시하고, 그 문제에 도달하기 위한 기본기 문제를 요청했다.
2. 평균·차이·나눗셈 중심의 초기 보충 제안에 대해 “StandardScaler가 어떻게 작용하는지 transform이 어떻게 적용하는지에 대한 문제들도 알려줘야지”라고 수정했다.
3. 목표 문제의 선수 지식과 코드 동작을 단계별로 설계하는 방식을 이후 문제 제작에도 적용하고, 커리큘럼 제작 과정을 계속 기록하며 발전시키도록 요청했다.

실제 개별 문항 답안, 학습 시간, 다음날 재시험 결과는 아직 없다. 특정 개념을 모른다고 확정한 진단은 아니다.

산술 보충과 함께 API의 역할, 저장된 기준, 호출 후 상태 유지, 배열 구조를 다루는 발판이 필요하다는 가설을 세웠다. 문제 생성 시 목표 코드에서 선수 지식을 역으로 분해하고, 코드 추적과 이유 설명으로 확인하는 절차를 채택했다.

### 변경

다른 숫자로 같은 문제를 반복한 것을 새 능력 근거로 세지 않도록 유형군을 도입했다. 한 번의 오답은 보충·재확인으로 연결하고 이전의 성공 근거는 유지한다. 추천에서는 학습 중인 개념을 이어가고 새 개념 수를 제한하며, 앞으로 낼 문제를 맞힌 것으로 가정하지 않는다.

## CD-20261018-003 · 문제 생산에서 운영 학습 경로 중심으로 통합

- 날짜: 2026-10-18, Asia/Seoul
- 관련: CR-010 / WBS-360 / 설계·계획 1.6.0 / 운영 `learning-paths-2.0`
- 상태: 운영 구현·Python313/Node14/모바일21 검증 완료(EV-025), 원격 게시 확인 중

### 근거와 방향

사용자가 배포를 요청한 뒤, 문제 그 자체보다 출시 전에 목표를 순서대로 배울 수 있는 커리큘럼과 사용자 수준 측정·적정 단계로 이끄는 구조를 실제 적용하는 것이 중요하다고 명시했다. 여러 경로 업데이트의 충돌을 고려해 최신성을 유지하도록 요청했다.

배포 점검에서 이 작업 공간이 최신 운영 main보다 오래되었음을 확인했다. 기존 작업은 소스 백업과 Git stash로 보존하고 main e5d8b23의 Python/SQL 트랙·기록 보존·복습·추가 학습을 기준으로 전진했다. 기존 70문항과 충돌하던 신규 pandas ID를 새 scaffold ID로 분리했다. 오래된 프로토타입 전체를 운영 소스에 덮어쓰지 않았다.

### 설계 판단과 실제 적용

- 목표별 기초·적용·전이, 선수 문항, 보충 경로, 과제 유형군을 모든 운영 문항에 작성했다. 새 목표에 부족한 자원만 보충하며 개별 검토 상태를 기록했다.
- 응용에 낮은 단계가 없거나 전이에 적용 단계가 없는 구조, 보류 서술 문항에 의존하는 구조를 출시 전에 차단한다. 기본 최소 난이도를 높여 기초 공백을 우회하던 추천을 제거했다.
- 부족한 기초와 중간 적용을 위한 21문항을 추가했다. 기존70개는 ID·버전·원본 전체 해시로 보존을 확인한다. 현재 운영91개와 별도 전처리 초안17개를 구분한다. 초안17개는 자동으로 출시하지 않는다.
- 학습 경로와 근거 기반 수준 판단을 웹/서버의 실제 새 묶음 추천에 적용했다. 초기 독립 알고리즘 실험은 코드·당시 문제 은행·가상 결과로 보존하고 운영은 v2 한 경로를 사용한다.
- 기본5문제 목표와 선택적 추가 학습·같은 날 ID 중복 방지·복습 기한을 유지한다. 기존 세션·snapshot·완료/미완료·저장 키는 바꾸지 않는다.

### 검증에서 발견한 문제와 수정

1. 같은 개념의 하루 첫 관찰만 사용하면 그 뒤 도움 사용이 누락되었다. 모든 완료 결과로 도움 필요와 회복을 확인한다.
2. 예정 복습이 먼저 나온 날의 새 독립 풀이를 무시하면 다양한 문제를 풀어도 단계가 열리지 않을 수 있었다. 다른 문항 수와 관찰 날짜 수를 분리하고, 날짜는 하루 한 번만 센다. 같은 날 연습으로 여러 날의 근거를 만들지 않는다.
3. NumPy 구조와 모델 지표에는 기초와 전이 사이 적용 단계가 빠져 있었다. 두 중간 자원을 연결하고 출시 검사와 전체 활성 문항 도달 회귀로 확인한다.
4. 카탈로그가 늘면서 모바일 회귀의 고정 시작일 이후 가상 이력이 현재 날짜를 넘었다. 가상 이력을 명확히 과거 날짜로 옮겼다. 실제 학습 날짜나 사용자 기록을 수정하지 않았다.

### 남기는 근거와 아직 확인하지 않은 효과
