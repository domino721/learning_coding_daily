## 개발·검증·배포 경로

작업 전에 origin/main을 fetch하고 비교한다. 로컬 수정은 먼저 보존하고 최신 배포 소스에 필요한 변경만 적용한다. `bash scripts/check.sh`, `npm run test:e2e`로 확인한 동일 소스를 main에 반영하고 기존 Pages 워크플로 결과를 확인한다. `npm run build:web`가 검증과 게시에 공통으로 쓰인다.

개발 중 웹 모드 미리보기는 `npm run dev -- --mode web`로 실행한다. 클라우드의 localhost는 외부 접속 링크가 아니다. 별도 단일 HTML을 새로운 학습·배포 채널로 제공하지 않는다. 이미 내려받은 과거 HTML은 자동 갱신되지 않으므로 앞으로는 기존 사이트를 사용한다.

다른 origin의 테스트 기록과 운영 기록이 자동 공유되지는 않는다. 운영 기록을 초기화하지 않으며, 필요하면 학습 기록 화면의 검증된 백업 가져오기를 사용한다. 실제 기기 데이터 유실이나 동기화 성공을 자료 없이 주장하지 않는다.
