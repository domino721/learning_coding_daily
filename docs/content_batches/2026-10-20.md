## 참조 풀이와 별도 재검수

각 원본 JSON의 code가 실행 가능한 참조 풀이이며 SQL은 reference_setup을 먼저 실행한다. 다음 계산으로 다시 풀고 실제 라이브러리/SQLite 출력과 대조했다.

1. 최대값12의 행은 C/A이고 원래 먼저 나온 C다. 값12·첫 행B·사전순A는 다른 반환 기준이다. 동점 없이 최대가 하나인 경우, 동점 순서 변경, 음수값을 별도로 확인했다. 전부 결측인 입력은 이번 지문에 없으며 그 반환 동작을 일반화하지 않는다.
2. 전치한 세 행 [1,4]/[2,5]/[3,6]을 각각 평균하면 [2.5,3.5,4.5]다. [2,5]는 원래 행 평균, [5,7,9]는 합계, [3.5]는 전체 평균이다. 전치 전후 행/열 수를 보조 선수로 확인한다. 단일 행·단일 열·음수 배열을 Python zip 기반 열 평균과 대조했다.
3. 행/열 모두 [1,0] 순서다. 실제1의 예측1/0 건수는 1/1, 실제0은 0/2다. 기본 클래스 순서, 축 뒤바꿈, 일부 열만 뒤바꿈은 각기 다른 오답이다. 클래스 순서 반전·한 클래스 부재·전부 반대 예측에서 직접 교차 집계를 확인했다.
4. 네 원본 행 중 결과 값은 {1,2} 두 개다. UNION ALL은 입력2+2=4개를 보존한다. 4/4는 둘 다 중복 보존, 2/2는 둘 다 제거, 3/4는 입력 내부 중복을 남긴다는 혼동이다. 양쪽 빈 표·한쪽 빈 표·입력 내부 중복·서로 다른 값·NULL 중복에서도 Python 집합/목록 건수와 일치했다.
5. 정수합1/정수건수3은0이다. 1.0을 먼저 곱한 두 번째 식은 ROUND(1.0/3,2)=0.33이다. 두 식 모두 실수, 둘 다 정수, 분모 무시가 다른 보기다. 모두 성공·모두 실패·0행(NULL,NULL)과 실수를 나눗셈 뒤에 곱하는 반례도 확인했다.
