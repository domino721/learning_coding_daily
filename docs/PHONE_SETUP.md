# 휴대폰에서 무료로 사용하기

이 버전은 GitHub Pages에 올려 사용하는 모바일 웹입니다. 별도 Python 서버나 유료 호스팅 계정 없이 기존 GitHub 계정으로 게시할 수 있습니다. GitHub Pages를 무료로 쓰려면 저장소가 공개 상태여야 합니다. 사이트 자체도 공개됩니다.

## 최초 한 번만 할 설정

소스가 GitHub 저장소의 main 브랜치에 올라간 다음 진행합니다.

1. 저장소의 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
3. 저장소의 **Actions → Publish mobile web → Run workflow**를 눌러 main 브랜치로 실행합니다.
4. 배포가 초록색으로 끝나면 실행 결과의 **github-pages** 또는 Settings → Pages의 **Visit site**를 누릅니다. 그 주소를 휴대폰에서 열면 됩니다.

이미 Push로 실행된 워크플로가 실패했다면 Pages 설정 후 새로 Run workflow를 실행하세요. 설정하기 전에 주소가 만들어졌다고 가정하지 마세요. 클라우드 환경의 **Publish**는 이 웹 게시와 별개입니다.

## 매일 사용하기

휴대폰 브라우저에서 사이트를 열어 **오늘 학습 시작하기**를 누릅니다. 5문제를 마친 뒤 완료 화면의 **추가로 5문제 풀기**로 계속 풀 수 있습니다. 홈에도 같은 버튼이 있고, 중간에 나갔다면 **추가 학습 이어서 풀기**가 표시됩니다. Safari의 공유 → 홈 화면에 추가, Android Chrome의 메뉴 → 홈 화면에 추가로 바로가기를 만들 수 있습니다. 기기에 따른 실제 설치 동작은 직접 확인해야 합니다.

학습 진도는 **현재 기기의 해당 브라우저 저장 공간**에 남습니다. 새로고침이나 브라우저 재실행 후 이어할 수 있지만, 방문 기록/사이트 데이터를 지우거나 시크릿 모드를 종료하면 기록을 잃을 수 있습니다. 기기나 브라우저 사이에 자동으로 공유되지 않습니다. 이 버전은 계정 동기화, 오프라인 실행, 푸시 알림을 지원하지 않습니다.

## 개발자가 확인할 사항

- `python3 scripts/export-content.py`가 서버 문제 원본을 `src/curriculum.json`으로 내보냅니다.
- `npm run build:web`는 API 서버가 필요 없는 결과물을 `web-dist/`에 만듭니다.
- `web` 모드에서는 학습 데이터를 브라우저에 저장하며 API로 전송하지 않습니다. GitHub Pages의 저장소 하위 경로에서 동작하도록 상대 경로를 사용합니다.
- 브라우저 채점이므로 콘텐츠에 정답도 포함됩니다. 개인 학습용이며 순위·시험 보안 기능이 아닙니다.
- GitHub Pages 설정 후 main에 push하면 워크플로가 새 결과물을 게시합니다.
- Python/SQLite 버전의 진도와 브라우저 버전의 진도는 별개입니다.
