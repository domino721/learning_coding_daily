# pandas 전체 문제의 단계별 설계 v0.2

작성일: 2026-10-18, Asia/Seoul. 대상: 현재 앱의 모든 pandas 문제 27개.

## 목표와 선수 지식

목표는 작은 표에서 필요한 행·열을 선택하고, 결측 처리·정렬·집계가 결과에 미치는 영향을 코드로 설명하는 것이다. Python 변수·리스트·비교 연산·함수 호출을 선수 지식으로 가정한다. 진단에서 부족하면 해당 문법의 보충 문제를 별도로 제작한다.

공통 [설계 기준](../CURRICULUM_DESIGN.md)과 [수준 판단·추천](../ADAPTIVE_LEARNING.md)을 적용한다. 전체 문제 카드는 [공통 문제 은행](../../curriculum/problem_bank.json)에 있으며, 실제 앱의 정답·문구·힌트 원본은 [backend/content.py](../../backend/content.py)다. 테스트가 둘의 일치를 확인한다.

## 단계와 이번 확장

기존 17개를 보존하고 개념별 `-scaffold-01` 기초·`-scaffold-02` 적용을 추가했다. 배포본의 기존 `-03`·`-04` ID를 재사용하지 않는다. 기초 문제는 필요한 새 API·속성을 문제에서 짧게 소개하고 하나의 결과를 확인한다. 응용에서도 새 도구의 의미를 먼저 설명한다. 이름이 같은 메서드를 외웠는지와 중간 결과를 추적하는지를 함께 확인한다.

| 개념 | 기존 기초·적용 | 추가 scaffold-01 | 추가 scaffold-02 | 오답 뒤 확인·보충 |
| --- | --- | --- | --- | --- |
| 열 선택 | 열 하나 선택 / 여러 열과 열 개수 | 선택한 Series의 이름 | 열 선택 뒤 유지되는 행 개수 | 행·열 축과 선택 대상을 짚고 01·02로 연결 |
| 행 필터링 | 조건의 True 행 수 / 경계 연산자 | 문자열과 같은 행 찾기 | 팀·금액 두 조건의 교집합 | 각 조건 결과를 먼저 표시하고 01·02로 연결 |
| 결측치 | 결측 확인 / 채우는 메서드 | 결측 행 제거 후 행 수 | 채우기 후 평균의 변화 | 제거·채우기 뒤 데이터와 분모를 확인하고 01·02로 연결 |
| 정렬 | 내림차순 / 값 정렬 메서드 | 유지되는 행 이름 읽기 | 두 정렬 기준의 우선순위 | 기준 열·순서·원래 인덱스를 구분하고 01·02로 연결 |
| 그룹 집계 | 합계 메서드 / 지정 그룹 합 | 그룹별 유효한 값의 건수 | 다른 그룹의 평균 계산 | 그룹에 속하는 행과 지표 정의를 확인하고 01·02로 연결 |

모든 문항 ID는 `pandas-개념-번호` 형식이며, 정확한 ID·목표·새 개념·선수 개념·오답 가설·진단 질문·힌트·보충 문제·진급 확인은 공통 문제 카드에 기록한다. 초기에 한 문제마다 적어도 하나의 오답 가설을 남겼으며, 선택지별 실제 혼동 여부는 사용자 자료를 보고 보완한다.

운영 추천에서는 열 선택을 공통 선수 개념으로 두고, 나머지 네 개념은 현재 경로 원본의 선수 문항을 확인한 뒤 연다. 이 선행 관계는 현재 가설이며, 진단상 이미 할 수 있는 사용자에게 불필요한 반복이 되는지 확인해야 한다. 운영 추천은 공통 v2 경로를 사용하며 그룹 집계의 선수는 현재 원본에 맞춰 필터 개념을 따른다.

## 진급 확인과 남은 제작

문항의 선수 경로를 따라 기초를 확인하고, 과제 유형과 서로 다른 날의 독립 해결·조건 변화·지연 복습으로 수준을 판단한다. 속도는 진급 조건에 쓰지 않는다. 카드의 이유 설명 질문은 수동 확인용이며 앱에서 자동 채점하지 않는다.

초기 프로토타입의 10문제 작업 뒤 최신 배포본과 통합하면서 기존 17개를 보존하고 새 ID로 10개를 추가했다. 새 문항 코드를 실행해 정답과 대조했다. 기존 10문제의 pandas 참조 검증도 유지한다.

다음 제작은 각 개념의 부족한 보충 경로와 추가 변형을 우선한다. 반복해 맞힌 같은 문제로 유형 다양성이 부풀지 않도록 숫자만 바꾼 문항은 같은 `family`로 묶는다. 실제 사용자 학습 효과는 아직 미검증이다.
