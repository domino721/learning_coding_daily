## 출발 근거와 도달 행동

사용자는 아래 문제의 해설을 보고도 기본기를 쌓을 문제가 필요하다고 설명했다. 평균 계산 위주의 보충 문제를 받은 뒤 `StandardScaler`와 `transform`의 작동을 다루는 문제도 필요하다고 명시했다. 실제 문제별 답안이나 힌트 없는 성공 기록은 아직 없다.

목표는 다음 코드를 보고 `3.0`을 예측하고, 어떤 데이터에서 기준을 구했는지와 각 호출·인덱싱의 역할을 설명하는 것이다.

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler().fit([[10.0], [20.0]])
value = scaler.transform([[30.0]])[0, 0]
print(round(float(value), 1))
```

실행 결과: `3.0`.

## 선수 지식과 단계

선수 지식은 리스트·변수·함수 호출, 평균, 뺄셈·나눗셈이다. 부족한 부분만 먼저 확인한다. 표준편차는 초기에 주어진 비교 단위로 사용하고, 직접 계산하는 과정은 별도 보충으로 둔다.

아래 ID는 설계용이다. 앱에 등록된 문항 ID가 아니다. 각 단계는 앞 문제의 객체 상태를 이어받지 않고 새 준비 코드로 시작하도록 제작한다.

이후 모든 트랙 공통 규칙에 맞춰 [문제 은행](../../curriculum/problem_bank.json)에 4개 개념·17문항으로 확장했다. SC-01은 `scaler-shape-01~03`, SC-02·03은 `scaler-fit-01~04`, SC-04·05·08은 `scaler-transform-01~05`, SC-06은 `scaler-shape-04`와 `scaler-transform-02`, SC-07은 `scaler-state-01~04`에 연결된다. 원래의 SC 번호는 학습 경로 설명용으로 보존한다. 카드의 전체 힌트·오답 가설·보충 경로·변형 확인은 공통 문제 은행에서 관리한다.

| ID | 목표와 새 개념 | 선수 문제 | 문제 설계와 기대 답 | 혼동 확인·보충 경로 |
| --- | --- | --- | --- | --- |
| SC-01 | 2차원 입력의 행·열 의미 | 리스트 기초 | `[[10], [20]]`의 데이터 수와 특성 수 → 2개, 1개 | `[[10, 20]]`과 비교하여 행과 열을 확인 |
| SC-02 | StandardScaler의 목적 | SC-01, 평균·표준편차의 의미 | 학습 데이터의 평균을 0으로 옮기고 표준편차를 단위로 삼는 변환을 소개하고, 평균에 해당하는 값의 변환 결과 확인 → 0 | 평균보다 크거나 작은 값의 부호를 비교하는 보충 |
| SC-03 | fit의 역할과 저장된 기준 | SC-02, 인덱싱 기초 | fit은 평균·표준편차를 구해 저장함을 소개하고, `[10, 20]`으로 fit한 `mean_[0]`, `scale_[0]` 확인 → 15, 5 | 평균 오류는 산술 보충; 저장한 값의 의미는 SC-02·03에서 확인 |
| SC-04 | transform의 계산 규칙 | SC-03 | 학습 데이터 `10, 20`을 변환 → -1, 1 | 사용한 평균과 나누는 값을 먼저 확인하고 SC-03 연결 |
| SC-05 | 새 입력에도 기준 유지 | SC-04 | `30, 40`을 변환 → 3, 5; 저장된 평균 → 15 | 평균을 35로 고르면 어느 데이터로 기준을 구했는지 묻고 SC-03·04 연결 |
| SC-06 | 결과 배열에서 값 추출·표시 | SC-05, float·round의 짧은 보충 | 목표 코드의 `transform` 결과는 `[[3.0]]`에 해당하며 `[0, 0]`으로 꺼낸 최종 출력은 `3.0` | 변환값은 맞고 추출이 틀리면 작은 2차원 배열 인덱싱 문제로 이동 |
| SC-07 | 다시 fit하면 기준 갱신 | SC-06 | `[30, 40]`으로 다시 fit한 뒤 30 변환 → -1 | fit 전후 저장된 평균을 나란히 확인 |
| SC-08 | 기준 적용을 새 숫자에 전이 | SC-06 | `[2, 6]`으로 fit, `12, 0` 변환 → 4, -2 | 정답뿐 아니라 기준 4와 2를 사용한 이유 확인; 혼동한 단계로 복귀 |

SC-07과 SC-08은 SC-06 이후의 확장이다. 다음날 복습에서는 학습값과 새 입력을 바꾸고, `fit`을 다시 호출한 위치를 설명하게 한다. 특성이 여러 개인 입력은 특성별 기준이라는 새 개념을 별도로 소개한 다음 다룬다.

StandardScaler는 기본 설정에서 특성별로 평균과 표준편차를 사용한다. 이 예시의 표준편차는 모집단 방식(`ddof=0`)으로 계산한 5다. 분산이 0인 특성의 처리와 `with_mean`·`with_std` 옵션은 후속 주제로 둔다.

## 첫 문제 카드: SC-05 · v1 · 설계 초안

- 학습 목표: 새 입력을 변환할 때 fit에서 저장한 기준을 사용한다고 설명한다.
- 선수 문제: SC-04. 배열 인덱싱과 출력 읽기는 이미 소개한 상태로 가정한다.
- 새 개념: 새 입력에도 학습 기준 유지.
- 유형: 출력 예측 + 짧은 이유 설명. 예상 시간: 1~2분, 미실측 추정.
- 문제: 다음 코드의 세 출력은 무엇인가? 계산에 쓴 평균은 어떤 데이터에서 구했는가?

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler().fit([[10.0], [20.0]])
result = scaler.transform([[30.0], [40.0]])
print(float(result[0, 0]))
print(float(result[1, 0]))
print(float(scaler.mean_[0]))
```

- 정답: 순서대로 `3.0`, `5.0`, `15.0`. 값의 의미를 묻는 수동 확인에서는 3, 5, 15도 허용한다. 앱 등록 시에는 제출 형식과 허용 문자열을 별도로 확정한다.
- 이유: fit 입력의 평균 15와 표준편차 5를 저장한다. transform은 각각 `(30-15)/5`, `(40-15)/5`를 계산한다. 저장된 평균은 15다.
- 오답 가설: `-1, 1, 35`라면 새 입력으로 기준을 다시 계산했을 수 있다. “fit에 전달한 데이터와 transform에 전달한 데이터를 각각 짚어보세요”로 확인한다.
- 힌트 1: 기준을 구한 호출과 그 호출에 전달한 데이터를 찾아보세요.
- 힌트 2: 저장된 평균은 15, 표준편차는 5예요. 먼저 `(30-15)/5`를 계산해보세요.
- 보충 경로: 기준이 혼동되면 SC-03, 식 적용이 혼동되면 SC-04. 인덱싱이 혼동되면 SC-01 이후 배열에서 한 값을 꺼내는 보충 문제.
- 진급 확인: SC-08을 힌트 없이 풀고 사용한 평균·표준편차의 출처를 설명한다. 단원 숙련 여부는 다음날 복습까지 보고 판단한다.
- 검증: Python 3.12.14 / scikit-learn 1.8.0에서 세 출력이 정답과 일치함을 확인했다. 실제 학습 결과는 미수집.

## 후속 코드 검증 예시

SC-04의 학습 데이터 변환:

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler().fit([[10.0], [20.0]])
print(scaler.transform([[10.0], [20.0]]).tolist())
```

기대 결과: `[[-1.0], [1.0]]`. `.tolist()`는 검증용 출력 정리이며 초기 학습의 평가 대상에는 넣지 않는다.

SC-07의 기준 갱신:

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler().fit([[10.0], [20.0]])
scaler.fit([[30.0], [40.0]])
print(float(scaler.transform([[30.0]])[0, 0]))
```

기대 결과: `-1.0`. 다시 fit한 평균 35와 표준편차 5를 사용한다.

SC-08의 숫자 변형:

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler().fit([[2.0], [6.0]])
print(scaler.transform([[12.0], [0.0]]).tolist())
```

기대 결과: `[[4.0], [-2.0]]`. 학습한 평균은 4, 표준편차는 2다.
