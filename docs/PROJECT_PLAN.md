# 매일코딩 — 데이터 분석 학습 설계 v0.3

## 제품 목표

매일 10~15분, 한 문제 1~3분 정도의 작은 연습을 통해 실무 데이터 분석 능력을 키운다. Python 기초를 아는 개인 사용자가 모바일에서 먼저 사용하고, 이후 출시를 고려한다. 짧은 일일 분량·간격 반복·단계적 성장을 어학 앱의 학습 방식에서 참고한다.

사용자가 말한 “pandas·실무 데이터 분석”은 **데이터 분석 전반**을 의미한다. pandas만의 학습 앱으로 제한하지 않는다. 하나의 앱에서 데이터 분석과 코딩테스트 트랙을 선택하고, 데이터 분석 안에 도구·분석 개념별 경로를 둔다. 통계와 머신러닝도 데이터 분석 트랙에 포함한다.

## 데이터 분석 전체 범위

| 영역 | 기초 | 다음 확장 |
| --- | --- | --- |
| Python·데이터 다루기 | 자료형, 함수, 파일, 오류 읽기 | 모듈, 텍스트·날짜, 재현 가능한 작업 |
| NumPy | 배열·shape·인덱싱·축·마스크 | 브로드캐스팅, 뷰/복사, 벡터화, 수치 처리 |
| pandas | 열/행 선택, 결측치, 정렬, 집계 | 조인·피벗·시간·문자열, 데이터 품질 |
| SQL | SELECT, WHERE, NULL, COUNT | GROUP BY/HAVING, JOIN, 서브쿼리·CTE·윈도 함수 |
| 통계·실험 | 대표값, 변동성, 가중/조건부 비율 | 표본·분포·추정·검정·A/B 테스트·교란·인과 해석 |
| scikit-learn·모델링 | 분할, fit/transform, 스케일링, 예측, 지표 | Pipeline, 교차 검증, 회귀/분류·트리, 튜닝·누수·해석 |
| 실무 분석·전달 | 목표와 지표, 분모·단위, 데이터 점검 | EDA·시각화, 가설 검증, 결과 설명과 의사결정 |

이 표는 전체 커리큘럼 범위다. 모든 항목이 이미 구현된 것은 아니다. 현재 은행에는 pandas 10문제와 NumPy·SQL·통계·scikit-learn 각 5문제, 총 30문제가 있다. 첫 세션부터 다섯 영역을 접하고 이후 개념을 확장한다. 기존 저장소·기기 기록과 호환하기 위해 데이터 분석 트랙의 내부 저장 ID `pandas`는 유지하며 사용자에게는 “데이터 분석”으로 표시한다.

## 하루의 경험

1. 오늘 학습을 시작하면 5문제를 받는다. 같은 날 다시 열면 같은 묶음을 이어간다.
2. 처음에는 코드 읽기와 짧은 구현을 섞고, 이후 오류 수정·분석 판단·실무 조합으로 확장한다.
3. 풀이 전에는 중립적인 제목·코드·필요 정보만 보여 준다. 풀이를 알려주는 개념 태그는 숨긴다.
4. 힌트는 요청했을 때만 두 단계로 제공한다. 정답 또는 해설 학습 후에는 개념과 이유를 설명한다.
5. 오래 막히면 해설로 마칠 수 있고, 정답 학습과 구분해 기록한다. 강제 제한시간은 없다.
6. 하루 결과와 최근 7일 학습일을 보여 준다. 놓친 날의 분량을 의무로 누적하지 않는다.

문제 작성의 구체적인 기준과 수정 예는 [콘텐츠 기준](CONTENT_GUIDELINES.md)을 따른다. 풀이 시간을 줄이기 위해 정답 단서를 본문에 노출하지 않는다.

## 난이도·복습

현재 구현은 문제별 복습일을 저장한다. 힌트·오답·해설 이력이 있으면 다음날, 처음부터 혼자 맞혔으면 3일 뒤를 복습 후보로 잡는다. 하루 복습은 최대 3개이며 새 문제와 섞는다. 새 콘텐츠가 부족하면 이전 문제를 “다시 연습”으로 명시해 총 5문제를 구성한다.

다음 단계에서는 선행 개념과 개념별 숙련도를 도입한다. 서로 다른 문제의 독립 정답, 다음날 복습, 힌트 사용을 함께 보며 수준을 올린다. 한 번 맞혔다고 숙련 처리하거나 느리다는 이유로 강등하지 않는다. 1/3/7/14일 간격, 진단 문제, 시간에 따른 힌트 제안은 아직 구현하지 않았다.

## 기술·기록 보존

- React·TypeScript·Vite로 모바일 우선 화면을 구현한다.
- 무료 GitHub Pages 웹 빌드는 동일한 콘텐츠를 사용하고 해당 기기 브라우저에 기록을 저장한다. 계정·기기 간 동기화·오프라인 실행·푸시는 미구현이다.
- Python 3.12·FastAPI·SQLite 서버 모드도 유지한다. NumPy·pandas·scikit-learn을 설치하고 SQL은 표준 SQLite로 참조 검증한다.
- 문제 원본은 `backend/content.py`이며 JSON 내보내기로 두 모드의 콘텐츠를 일치시킨다.
- 이미 완료한 브라우저 기록은 보존한다. 미완료 카드만 최신 문구로 갱신하고 오늘의 문제 ID·순서·완료 수는 유지한다. 새 분야 구성은 다음 일일 세션부터 적용된다.
- 사용자 코드를 API 프로세스에서 실행하지 않는다. 자유 코드 문제는 별도 Worker/격리 실행 설계 후 추가한다. 서버 모드는 현재 한 개인의 기록을 공유하는 개발 버전이다.
